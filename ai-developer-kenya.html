Chatbot vs. agent — the difference that matters

Most "AI-powered" business tools are a chat box wired to an API — it answers a question and forgets everything else. An agent is different: it can plan a multi-step task, use tools (search, files, code execution), remember context across a session, and — critically — know when to stop and ask a human before doing something risky.

I build both, depending on what a business actually needs. A simple FAQ chatbot embedded on a site is sometimes exactly right. Other times, the real value is in an agent that can research, draft, and act — which is a different engineering problem entirely.

What this looks like for a business

Content and drafting agents

Research and automation agents

Multi-step agents that gather information or automate a repetitive workflow — the deeper end of what's technically possible today.
